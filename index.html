上传文件

点击选择文件，或把文件拖到这里 支持多选。图片：jpg、png、gif、webp、svg、bmp、ico；音频：mp3、wav、m4a、ogg、flac、aac
使用说明
  1. 先在上方填入 Token 并点「保存 Token」，Token 只保存在这台电脑的浏览器里，下次打开不用重填。
  2. 点击或拖入文件上传，同名文件会自动改名，不会覆盖旧文件。
  3. 在图库里点「复制」得到 github.io 外链，可以直接用在网页、笔记或文章里。
  4. 新上传的文件需要 GitHub Pages 部署 1～2 分钟，这期间外链可能打不开；卡片上显示「部署中」时，预览暂时走 GitHub 原始地址。
  5. 用户名、仓库名和分支写在本文件 JS 顶部，换仓库时只改那三行。
